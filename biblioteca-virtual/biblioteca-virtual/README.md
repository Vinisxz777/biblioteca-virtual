# Biblioteca Virtual

Landing page responsiva para um catálogo de livros, desenvolvida como exercício prático integrador de HTML5, CSS3 e JavaScript.

## Funcionalidades

- Catálogo com seis livros e informações de autores e gêneros.
- Busca em tempo real pelo título, sem diferenciar maiúsculas e minúsculas.
- Mensagem quando nenhum livro corresponde à pesquisa.
- Formulário para sugerir novas aquisições.
- Validação do nome e do título (mínimo de 3 caracteres).
- Layout responsivo para computadores, tablets e celulares.

## Tecnologias

- **HTML5:** estrutura semântica da página.
- **CSS3:** variáveis em `:root`, Flexbox, CSS Grid e Media Queries.
- **JavaScript:** eventos `input` e `submit`, `toLocaleLowerCase()`, `hidden`, `preventDefault()` e `textContent`.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências nem utilizar servidor.

## Estrutura de arquivos

```text
biblioteca-virtual/
├── index.html
├── style.css
├── app.js
└── README.md
```

## Observação

O formulário demonstra a validação e a confirmação da sugestão no próprio navegador. Ele não envia os dados para um servidor ou banco de dados.
